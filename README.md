# 题库检索（离线单文件版）

一个零依赖的离线题目检索工具：单个 HTML 文件内置 2242 道题（单选 578 / 多选 582 / 判断 603 / 填空 479），输入题干片段即可模糊匹配出答案、选项与知识点。

## 特性

- **单文件**：HTML + CSS + JS + 数据全部内联在 `index.html`，无任何外部依赖
- **离线可用**：双击浏览器打开即用，不需要网络、不需要安装
- **模糊匹配**：基于双字 Dice 相似度 + 子串包含，括号全半角、标点、空格、题号差异均可命中
- **实时检索**：输入即搜，按相似度排序，展示前 30 条
- **键盘操作**：↑↓ 选择结果，Enter 复制答案；点击答案也可复制
- **响应式**：手机与电脑浏览器均可用

## 使用

下载 `index.html`，用任意现代浏览器打开，粘贴或输入题目片段即可。

## 部署到 GitHub Pages（可选）

1. 新建仓库，把 `index.html` 和 `README.md` 传上去
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可在线使用

## 说明

- 题库数据来源于课程配套知识点解析文档，仅供个人学习复习使用
- 公开仓库会同时公开全部题目与答案，发布前请自行确认是否合适；如只想自用，建议设为 Private 仓库（Private 仓库也可以开 Pages，但需要 GitHub Pro）
